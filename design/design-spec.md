# Design Spec — วังสามหมอ Food Delivery

## Color Palette

| Name | Hex | Usage |
|---|---|---|
| Primary | #FF6B35 | ส้ม — header, ปุ่มหลัก, brand |
| Secondary | #2EC4B6 | เขียวมิ้นต์ — สำเร็จ, positive |
| Dark | #1A1A2E | ตัวอักษรหลัก |
| Gray | #6C757D | ตัวอักษรรอง |
| Warning | #E71D36 | แดง — ปฏิเสธ, ยกเลิก |
| Background | #F8F9FA | พื้นหลัง |
| White | #FFFFFF | การ์ด |

## Typography

- หัวข้อ: Sarabun Bold (ไทย) / Inter Bold (EN)
- เนื้อหา: Sarabun Regular (ไทย) / Inter Regular (EN)
- ขนาด: 24px (h1), 18px (h2), 16px (body), 14px (meta), 12px (caption)
